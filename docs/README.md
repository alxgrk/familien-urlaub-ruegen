# Documentation

Human-oriented documentation for the **Familiencamp Rügen** website. These docs are written for different audiences — pick the one that fits you.

## Who should read what

| Document | Audience | What it covers |
| --- | --- | --- |
| [overview.md](overview.md) | Owners, non-developers | What the website is, what it does, and how it's put together in plain language |
| [content-guide.md](content-guide.md) | Content editors | How to change texts, prices, season dates, photos, and PDFs without touching code |
| [booking-flow.md](booking-flow.md) | Everyone curious | How the booking-inquiry form works from the visitor's click to your inbox |
| [architecture.md](architecture.md) | Developers | How the code is organized: pages, components, styling, and data |
| [deployment.md](deployment.md) | Developers / admins | How to build, export, and publish the site on Netlify |

## Also in this repo

- **`AGENTS.md`** (repo root) — a more technical, developer/agent-oriented companion to `architecture.md`, including pitfalls.
- **`README.md`** (repo root) — short landing page with quick-start commands.
